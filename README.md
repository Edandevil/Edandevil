# Sanches Studio Portfolio

A high-end, motion-focused personal portfolio website inspired by the **Sanches** studio aesthetic.

## 🚀 Key Features
- **Sanches Aesthetic**: Massive asymmetrical layered typography with "barcode" textures and gradient accent box effects.
- **Fluid Motion**: Kinetic smooth scrolling powered by **Lenis.js** for a momentum-based browsing experience.
- **Visual Excellence**: Deep black true-dark theme, 80px background structural grid, and subtle analog grain texture overlays.
- **3D Visual Storytelling**: High-quality 3D black chrome bust with Crimson and Purple rim lighting.
- **Minimalist Navigation**: Clean top-row menu with a gradient "Say hi" action link.

## 🎨 Design System
- **Colors**: 
    - Pure Black (`#000000`)
    - Sanches Crimson (`#FF1F44`)
    - Electric Purple (`#8855FF`)
- **Typography**: 
    - Display: **Space Grotesk**
    - Body: **Inter**

## 🛠️ Tech Stack
- **HTML5** (Semantic structure)
- **Vanilla CSS3** (Custom properties, Flexbox/Grid, Animations)
- **Lenis.js** (Smooth Scroll)

## 🏁 Quick Start
1. Clone the repository:
   ```bash
   git clone https://github.com/Edandevil/Edandevil.git
   ```
2. Open `index.html` in your browser.
3. For the best experience, use a local server:
   ```bash
   npx http-server
   ```
